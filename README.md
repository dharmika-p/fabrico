Fabricó is a full-stack e-commerce web application built using the MERN stack that enables users to browse, purchase, and manage clothing products through a secure and responsive platform. The application includes separate user and admin interfaces with authentication, cart management, and order tracking features.
User Side

User authentication using JWT

Browse products with images, prices, and categories

Add to cart & update quantities

Secure checkout

Order history and tracking

Admin Side

Admin authentication

Add, edit, and delete products

Manage orders and users

Inventory and order management
